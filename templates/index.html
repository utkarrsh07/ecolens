Methodology

From report-card grades to a restoration priority

Every number in EcoLens is calculated in Python with fixed, published rules. Nothing is estimated by AI. The values below are read directly from the scoring engine.

  1. 1

    Grades become scores

    Each published letter grade is converted to a 0–100 score.

    {% for grade, score in engine_config.grade_map.items() %} {{ grade }} {{ score }} {% endfor %}
  2. 2

    Two condition domains

    Indicators are combined with fixed weights. Unreported indicators are excluded and the remaining weights are re-normalised.

    Forest

    {% for name, weight in engine_config.forest_weights.items() %}
    {{ name }}{{ '%g'|format((weight * 100)|round(1)) }}%
    {% endfor %}

    Surface water

    {% for name, weight in engine_config.water_weights.items() %}
    {{ name }}{{ '%g'|format((weight * 100)|round(1)) }}%
    {% endfor %}
  3. 3

    Environmental health

    The average of the available domain scores.

    Health = mean(Forest, Surface water)

    If no component grades exist, the published overall grade is used and evidence coverage drops to {{ engine_config.fallback_coverage }}%.

  4. 4

    Stress index

    Each component score becomes a severity (≥80 → 0, ≥60 → 25, ≥40 → 60, below 40 → 100), then a weighted average.

    {% for name, weight in engine_config.stress_weights.items() %}
    {{ name }}{{ '%g'|format((weight * 100)|round(1)) }}%
    {% endfor %}
  5. 5

    Restoration priority

    Poor overall condition matters most; concentrated severe indicators raise priority further.

    Priority = {{ engine_config.condition_weight }} × (100 − Health) + {{ engine_config.stress_weight }} × Stress
    {% for label, minimum in engine_config.priority_thresholds.items() %} {{ label }} ≥ {{ minimum }} {% endfor %}

What these scores can and cannot tell you

  • Grades, not measurements. Inputs are Conservation Halton's published letter grades, not raw sensor data. The source data is the 2023 report card, not real-time readings.
  • Weights are assumptions. The grade-to-score values, weights and thresholds are EcoLens design choices, shown in full above so they can be challenged.
  • Evidence coverage is not statistical confidence. It measures how much of each domain's indicator weight was actually reported.
  • Decision support only. Rankings are a starting point for discussion and field review, not an official assessment.
